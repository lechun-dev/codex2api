## MySQL 5.6 / 8.0 适配

- 新增 Kiro、静默时间、输出保护设置的建表及存量升级定义；TEXT 设置继续使用 Go 端默认值，不依赖 JSON 类型或 TEXT 默认值。
- 新增账号用量权限、重置请求去重、跨实例租约和冷却记录表。标识列使用有界 ASCII 二进制排序规则，兼顾精确匹配与 5.6 的索引长度限制。
- 租约/冷却使用先初始化、再原子条件更新的方式，兼容现有 `clientFoundRows` 配置，避免 PostgreSQL upsert WHERE 及受影响行数差异造成重复授权。
- 配额窗口和 API Key 元数据查询使用派生 UNION ALL 表，避免 CTE、JSON 函数、窗口函数等 5.6 不支持的语法；参数保持绑定。
- 流量统计使用 MySQL 时间函数，并保留上游将未刷盘完成请求计入快照的逻辑。
- 智能检测支持分来源开关、Kiro 分类和凭据代次隔离；对代次数值使用完整边界，避免将 1 匹配成 10。新增账号在插入事务内建立检测档案，默认未启用时也能手动开启。
- MySQL 账号用量权限投影只返回允许公开的字段；凭据文本损坏时拒绝授权，不将解析失败误当成无限制账号。
- 沿用已有字符集与升级方式；不引入 MySQL 8 专用排序规则、降序索引或不兼容 DDL。
